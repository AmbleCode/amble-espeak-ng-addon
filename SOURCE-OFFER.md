# Offer of source

The complete corresponding source of every package published here is attached to the same release as the
package, as `espeak-ng-<version>-source.tar.gz`. It is free to download for as long as the package is.

If you received a package and cannot get that archive, you may ask for it in writing. We will send the source
for the exact version you received on a physical medium or by download, for no more than the cost of doing so.
This offer is valid for at least three years after you received the package.

Send requests to:

support@lyrestudio.net

Include the package file name and the date you received it.
